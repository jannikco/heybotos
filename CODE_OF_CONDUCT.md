# Code of conduct

Be kind, be direct, and assume the other person means well.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: no harassment, no personal attacks, no publishing of other people's private information. Disagree
about the work, not about the person.

If someone's behaviour here troubles you, tell the maintainers through GitHub's private reporting on the
repository's **Security** tab, or by contacting a maintainer directly. Reports are kept confidential.
